# 商品ページへの埋め込み

Wix の商品ページ（[basketball-gear-bags](https://www.rankup-sports.com/product-page/basketball-gear-bags)）の
**レビューブロックのすぐ上**に、この LP を iframe で載せるための一式です。

商品ページはクラシック Wix（`--site-width: 980px` / レスポンシブ版ではない）。
GitHub Pages 側は `X-Frame-Options` も CSP も返していないので、iframe 埋め込みはブロックされません。

## 枠のサイズ（どちらのモードでも共通）

Wix の「HTML コードを埋め込む」要素は中身の高さに追従しないので、**エディタ側で枠のサイズを指定**します。
中身は指定した枠いっぱいに広がります。

| | 幅 | 高さ |
|---|---|---|
| PC | 980px（サイト幅いっぱい） | 820px |
| モバイル | 320px（モバイル canvas いっぱい） | 560px |

- 980px にしているのは、ブロック03/04 が **968px 基準の固定レイアウト**で組まれているため。
  980px なら拡大率がほぼ 1.0 倍 ＝ デザインの実寸で出る。
- 高さは1画面ぶんに近い 820px。控えめにしたいときは 980 x 620 でも成立する（下限 420px まで自動追従）。

## モード別

### A. コードモード → [`wix-product-page.html`](wix-product-page.html)

追加(+) → 埋め込み＆ソーシャル → 「HTML コードを埋め込む」→ **「コードを入力」** に貼る。
角丸・影・「全画面で見る」ボタンまで込みで完結する。

### B. URL 指定モード → [`index.html`](index.html)

同じ要素の **「ウェブサイトのアドレス」** に下の URL を貼る。
URL モードはコードを差し込めないので、装飾はこのラッパーページ側に持たせている。

```
https://rankupsports.github.io/basketball-gear-bags/embed/
```

装飾が不要なら LP を直接指定してもよい（iframe が1枚減って軽い）。

```
https://rankupsports.github.io/basketball-gear-bags/
```

## 特定の商品ページだけに出す

クラシック Wix の「商品ページ」は**全商品共通のテンプレート1枚**なので、そこに埋め込むと全商品ページに LP が出る。
特定商品だけにしたい場合は次のどれか。

| 方法 | 内容 |
|---|---|
| **Velo で条件表示**（推奨） | [`velo-product-page.js`](velo-product-page.js) を商品ページのページコードに貼る。スラッグが一致した商品でだけ `expand()`、それ以外は `collapse()`（領域ごと詰める）。要素側は「読み込み時に折りたたむ」にしておく |
| LP 専用ページを作る | 通常ページを1枚追加してそこに埋め込み、商品ページからはリンクで飛ばす。Velo 不要 |
| 商品説明にリンクだけ入れる | 商品説明は商品ごとに書けるので、全商品に影響しない。ただし iframe は貼れず、リンクのみ |

なお、ダッシュボード（管理画面）にレイアウト編集の機能はないので、埋め込み要素の配置は**エディタ**で行う
（ダッシュボード → 「サイトを編集」→ ページ＆メニュー → 店舗ページ → 商品ページ）。

## 枠内をスクロールしたら全画面へ

枠の中で LP をスクロールさせるのをやめ、**スクロール操作を全画面表示のきっかけ**に使う。
プレビュー中は iframe を `pointer-events: none` にしてあるので、LP 側がスクロールを食わない
（＝商品ページのスクロールを奪わない）。

| 環境 | 挙動 |
|---|---|
| スマホ・タブレット | 縦スワイプで**そのまま全画面**。スワイプ終わりの `touchend` はブラウザ仕様で有効な「ユーザー操作」なので Fullscreen API が通る（20px 以上動いたらスクロールと判定） |
| PC（ホイール） | 中央にプロンプトが出て**1クリックで全画面**。`wheel` は仕様上ユーザー操作に数えられず Fullscreen API が拒否されるため、スクロールだけで全画面にはできない |
| 枠内のクリック | どこをクリックしても全画面 |
| Fullscreen API 非対応（iPhone Safari など） | 別タブで LP を開く |
| JS 無効 | 右下チップがただの別タブリンクとして機能する |

全画面中は iframe の操作を戻すので LP は普通にスクロールできる。右上の「閉じる」または Esc でプレビューに戻る。

- 1度ホイールで弾かれたら以降は API を呼ばずプロンプトだけ出す（コンソールに警告を溜めないため）。
- **Wix 側の iframe が fullscreen を許可していない場合**は全画面に入れず、クリック時は別タブ表示にフォールバックする。
  実機で確認して、全画面にならないようなら「別タブで開く」導線として運用すればよい。

## メモ

- どちらも `loading="lazy"`。レビュー位置までスクロールされるまで LP 内の動画（合計 60MB 超）は読み込まれない。
- LP 内の BUY NOW はリンクを切ってあるので、商品ページ → LP → 商品ページ のループにはならない。
  復活させるときはルートの `index.html` の `BUY_LINK` を `true` に戻す。
